# Documents — Context

Реализация — [ADR-090](../../adr/ADR-090-chat-documents.md); поле ответа хода — [ADR-101](../../adr/ADR-101-chat-response-documents.md).

## Зависимости
- **API Gateway** — auth (JWT), провижининг, ограничение частоты (`enforce_other_limits`, бакет `rl:other:{userId}`), маршруты `/v1/chats/{sessionId}/documents/*`.
- **Chats** — `chat_sessions`: документ адресуется парой (владелец, сессия); проверка существования сессии при создании; каскадное удаление документов вместе с чатом.
- Таблица **`chat_documents`** ([03-data-model §22](../../03-data-model.md), миграция `0027`).

## Потребители
- **chat-orchestrator** — исполняет `document.*` как global server-side tools внутри tool-loop (без проекта, без round-trip к устройству) и добавляет строку о документах в системный промт. По [ADR-101](../../adr/ADR-101-chat-response-documents.md) он же собирает поле `ChatResponse.documents[]` (turn-scoped; паттерн двух производителей взят у `mediaJobs`, восстановление по ходу **безусловное** — [ADR-101 §4](../../adr/ADR-101-chat-response-documents.md); у самого `mediaJobs` то же условие задано нормой позже — [ADR-103](../../adr/ADR-103-media-jobs-turn-scoped-merge.md), и там оно уже написано в коде и покрыто тестами, но не отревьюено, не слито в `main` и не выкачено).
- **iOS-приложение** — список документов чата, открытие, скачивание файлом, загрузка своего документа.

## Соседи (важно не путать)
- **`files.*` / code-tools ([ADR-094](../../adr/ADR-094-code-assistant-tools.md))** — client-side: исполняет **устройство пользователя**. Одноимённость по смыслу («файл») — главная ловушка этого модуля.
- **website-builder `site.*` ([ADR-011](../../adr/ADR-011-server-side-tools.md))** — тоже server-side, но результат — HTML-сайт в `site_files`, отдаваемый preview-роутом с sandbox-заголовками.
- **Файлы-знания workspace ([ADR-036](../../adr/ADR-036-workspaces-implementation.md))** — принадлежат проекту и переживают чаты; read-only для модели; наружу отдаются только метаданные. Правило «файл переживает сессию» на документы **не переносится**, правило «модель может изменить» на файлы-знания **не переносится**.
- **Медиа-ассеты ([ADR-085](../../adr/ADR-085-media-asset-download-proxy.md))** — отдаются по подписанному URL, потому что их тянет webview. Документ отдаётся по JWT. Ни одно из двух правил на соседа **не переносится**.

## Границы
- Модуль не вызывает LLM и не знает о ней: он предоставляет CRUD и строку контекста, а решение звать инструмент принимает orchestrator.
- Модуль не участвует в биллинге и не пишет в ledger.
- Модуль не вызывает модерацию ([00-overview BR-DOC-8](00-overview.md#бизнес-правила)).
