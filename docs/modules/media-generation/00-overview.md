# 00 — Обзор

Модуль даёт iOS-клиенту генерацию **изображений** и **видео** через провайдера fal.ai.

## Что делает

| Операция | Эндпоинт | Синхронность |
|---|---|---|
| Узнать доступные модели и их цены | `GET /v1/media/models` | синхронно, справочно |
| Сгенерировать изображение | `POST /v1/media/images` | `202` + задача |
| Сгенерировать видео | `POST /v1/media/videos` | `202` + задача |
| Узнать состояние задачи | `GET /v1/media/jobs/{jobId}` | синхронно, опрашивает провайдера |
| Посмотреть свои задачи | `GET /v1/media/jobs` | синхронно, из БД |

## Модели MVP

| Публичный id | Модель | Тип | Референсное изображение |
|---|---|---|---|
| `nano-banana-pro` | Nano Banana Pro (Gemini 3 Pro Image) | изображение | до 14 (режим редактирования) |
| `nano-banana-2` | Nano Banana 2 (Gemini 3.1 Flash Image) | изображение | до 14 (режим редактирования) |
| `kling-video` | Kling Video 2.5 Turbo Pro | видео | 1 (image-to-video) |
| `kling-video-v3` | Kling Video V3 Pro | видео | 1 (image-to-video) |
| `veo-3.1` | Veo 3.1 (Google) | видео | 1 (image-to-video) |

Публичные id — стабильный контракт: клиент присылает их в поле `model`. Идентификаторы endpoint'ов fal остаются на сервере.

## Ключевые свойства

- **Асинхронно.** Видео у Kling и Veo генерируется минутами, поэтому POST только ставит задачу в очередь. Результат забирается опросом.
- **Цена — серверная.** В теле запроса нет поля цены; стоимость берётся из реестра моделей и опционального override `MEDIA_MODEL_CREDITS`.
- **Провал возвращает кредиты.** Если генерация упала у провайдера, задача переходит в `failed`, а списанные кредиты возвращаются на баланс.
- **Каталог самодокументирован.** Допустимые значения `aspectRatio`/`resolution`/`duration` приходят из `GET /v1/media/models`, поэтому добавление модели не требует релиза клиента.
- **Опционально по инстансу.** Без `FAL_API_KEY` генерация отвечает `503 media_generation_not_configured`.

Решение и его обоснование — [ADR-060](../../adr/ADR-060-media-generation-fal.md).
