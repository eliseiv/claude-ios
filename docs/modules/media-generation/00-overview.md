# 00 — Обзор

Модуль даёт iOS-клиенту генерацию **изображений** и **видео** через провайдера fal.ai.

## Что делает

| Операция | Эндпоинт | Синхронность |
|---|---|---|
| Узнать модели, режимы, параметры и цены | `GET /v1/media/models` | синхронно, справочно |
| Сгенерировать изображение | `POST /v1/media/images` | `202` + задача |
| Сгенерировать видео | `POST /v1/media/videos` | `202` + задача |
| Узнать состояние задачи | `GET /v1/media/jobs/{jobId}` | синхронно, опрашивает провайдера |
| Посмотреть свои задачи | `GET /v1/media/jobs` | синхронно, из БД |

## Модели MVP

| Публичный id | Модель | Тип | Базовая цена | Референсное изображение | Длительность | Разрешение |
|---|---|---|---|---|---|---|
| `nano-banana-pro` | Nano Banana Pro (Gemini 3 Pro Image) | изображение | 8 / изображение | до 14 (режим редактирования) | — | `1K`/`2K`/`4K` |
| `nano-banana-2` | Nano Banana 2 (Gemini 3.1 Flash Image) | изображение | 4 / изображение | до 14 (режим редактирования) | — | `0.5K`/`1K`/`2K`/`4K` |
| `kling-video` | Kling Video 2.5 Turbo Pro | видео | 120 / 5 с | 1 (image-to-video) | `5`, `10` | — |
| `kling-video-v3` | Kling Video V3 Pro | видео | 200 / 5 с | 1 (image-to-video) | `3`…`15` | — |
| `veo-3.1` | Veo 3.1 (Google) | видео | 300 / 8 с | 1 (image-to-video) | `4s`, `6s`, `8s` | `720p`/`1080p`/`4k` |

Публичные id — стабильный контракт: клиент присылает их в поле `model`. Идентификаторы endpoint'ов fal остаются на сервере.

## Режимы и параметры

У каждой модели **два режима**, и клиент не выбирает их отдельным полем — режим определяется наличием референсного изображения:

| Есть картинка? | Изображения | Видео |
|---|---|---|
| нет | `textToImage` — генерация с нуля | `textToVideo` |
| да | `imageToImage` — редактирование | `imageToVideo` (картинка = стартовый кадр) |

Параметры: `aspectRatio`, `resolution`, `duration`, `numImages`, `outputFormat`, `negativePrompt`, `generateAudio`, `cfgScale` (только Kling), `seed`. Какие из них принимает конкретный режим и какие значения допустимы — в `modes[]` каталога; наборы различаются не только между моделями, но и между режимами одной модели (у Veo `aspectRatio: "auto"` доступен только с картинкой, у Kling в image-to-video соотношение берётся из кадра).

## Ключевые свойства

- **Асинхронно.** Видео у Kling и Veo генерируется минутами, поэтому POST только ставит задачу в очередь. Результат забирается опросом.
- **Цена — серверная.** В теле запроса нет поля цены; стоимость берётся из реестра моделей и опционального override `MEDIA_MODEL_CREDITS`, а затем масштабируется объёмом выпуска: `× numImages` у изображений, `× ceil(duration / базовая)` у видео.
- **Провал возвращает кредиты.** Если генерация упала у провайдера, задача переходит в `failed`, а списанные кредиты возвращаются на баланс.
- **Каталог самодокументирован.** Режимы, параметры и допустимые значения приходят из `GET /v1/media/models`, поэтому добавление модели не требует релиза клиента.
- **Опционально по инстансу.** Без `FAL_API_KEY` генерация отвечает `503 media_generation_not_configured`.

Решение и его обоснование — [ADR-060](../../adr/ADR-060-media-generation-fal.md).
