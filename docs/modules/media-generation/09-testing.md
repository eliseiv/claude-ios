# 09 — Тест-план

Провайдер в тестах никогда не вызывается по сети: `httpx` подменяется **только внутри** `app.media_generation.fal_client` (surgical monkeypatch), поэтому собственный ASGI-клиент теста не затронут. БД — общий testcontainers PostgreSQL с применёнными миграциями.

## Unit

### `tests/unit/test_media_catalog_adr060.py`
- состав реестра и стабильность публичных id (`nano-banana-pro`, `nano-banana-2`, `kling-video`, `kling-video-v3`, `veo-3.1`); разбивка по типам 2 image / 3 video;
- endpoint'ы совпадают с идентификаторами моделей fal (по паре на модель: prompt-only и с картинкой);
- имя поля с референсным изображением per-family, включая `start_image_url` у Kling v3 и списочный `image_urls` у image-моделей;
- трансляция camelCase → snake_case;
- `build_fal_input`: отбрасывает `None` (дефолты провайдера применяются) и поля, которых нет в allowlist варианта (`negative_prompt` у Veo, `aspect_ratio` у Kling image-to-video);
- у каждого варианта есть `prompt`, цена положительна.

### `tests/unit/test_media_generation_units_adr060.py`
- парсинг `MEDIA_MODEL_CREDITS`: валидная карта; не задано; кривой JSON / не-объект → без override; `0` / отрицательное / `bool` / строка / float → override **отброшен**;
- приоритет override над каталогом; отброшенный override **не делает запуск бесплатным**;
- в схемах запроса нет поля цены (anti-tamper);
- нормализация результата image (`images[]` → `assets`) и video (`video` → `assets`), включая случаи без пригодного URL → пустой `assets`.

### `tests/unit/test_media_schemas_adr060.py`
- `extra=forbid`; пустые `model`/`prompt`; лимит длины промта; `numImages` 1–4; `outputFormat` только из набора;
- allowlist схемы URL: `http://`, `file://`, `data:`, `//host`, `https:/host` → `422`; `https://` принимается; больше 14 картинок → `422`.

## Integration — `tests/integration/test_media_generation_adr060.py`

Полный HTTP-путь через реальную JWT-аутентификацию, реальное списание/возврат и реальную персистентность.

**Каталог:** состав и порядок моделей, положительные цены, применение `MEDIA_MODEL_CREDITS`.

**Контракт сабмита:** URL очереди совпадает с endpoint'ом модели; тело — snake_case-поля модели; заголовок `Authorization: Key …` (не `Bearer`); наличие картинки переключает endpoint на `/edit` и `image-to-video`; `start_image_url` у Kling v3 против `image_url` у Kling 2.5.

**Валидация до списания** (`422`, ноль исходящих вызовов, баланс не изменился): неизвестная модель; video-модель на маршруте изображений; значение вне набора модели (`duration: "12s"` у Veo); параметр, которого у модели нет (`resolution` у Kling).

**Биллинг:** `202` списывает цену модели; `409 insufficient_credits` при недостатке — без исходящего вызова; `502`/таймаут на сабмите → **списание откатилось** и строки задачи нет.

**Ошибки провайдера:** `401` → `503 media_generation_not_configured`; незаданный `FAL_API_KEY` → `503` без исходящего вызова; `422` → имя проблемного параметра доезжает до клиента.

**Опрос:** `IN_PROGRESS` → `running`; `COMPLETED` → `completed` + нормализованные `assets`; терминальная задача отдаётся из БД **без повторного вызова провайдера**; `FAILED` → `failed` + возврат кредитов, повторный опрос **не** возвращает второй раз; `COMPLETED` с пустым выводом → `failed` + возврат.

**Отказ уже принятого запуска:** `COMPLETED` + `422` из response URL (наблюдалось живьём с недостижимой картинкой) → `200` со `status: failed`, возвратом и текстом провайдера в `error`; повторный опрос не ходит наверх и не возвращает дважды. То же для `422` из status URL. В противоположность им `503` от провайдера при опросе → `502` клиенту, задача остаётся нетерминальной **и невозвращённой**, а следующий опрос доводит её до `completed`.

**Листинг и изоляция:** newest-first, без опроса провайдера; фильтр `kind`; чужая задача → `404` и отсутствует в списке; несуществующая → `404`; `401` на всех пяти маршрутах.

## Живой прогон против fal

Выполнен 2026-08-04 на локальном стеке с реальным ключом: все пять моделей дошли до `completed` с проверяемыми ассетами, в text-only и в режиме с референсной картинкой (изображения 13–20 с, видео 90–100 с). Сверено фактическое списание (`4/8/120/200/300`), бесплатность отказов, изоляция владельца, отсутствие ключа в логах и БД. Прогон выявил дефект «`422` при опросе», исправленный в `service._advance` и закрытый двумя тестами выше.
