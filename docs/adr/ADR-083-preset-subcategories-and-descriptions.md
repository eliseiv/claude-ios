# ADR-083 — Подкатегория и описание пресета на `GET /v1/presets`

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Связано:** [ADR-035](ADR-035-prompt-presets-endpoint.md) (каталог), [ADR-049](ADR-049-presets-localization.md) (локализация), [ADR-080](ADR-080-preset-categories.md) (жанр `work` / `life` / `entertainment`)

## Контекст

Экран «Агенты» раскладывает 18 карточек по трём вкладкам и рисует под заголовком однострочную подпись («Улучшает тексты, письма и документы»). Жанр уже отдаёт `category` ([ADR-080](ADR-080-preset-categories.md)), но:

1. Исходные семь чипов главного экрана оставались `category: null`, хотя клиент просит жанр у **всех** пресетов.
2. Подпись карточки клиент хардкодил по `id`.
3. Чип и карточка агента — разные `id` с близкой ролью (`plan_week` ≈ `planner`); без стабильного указателя клиент снова хардкодит раскладку.

Ограничение то же, что у ADR-080: живые iOS не должны ломаться. Поля `id` / `title` / `icon` / `prompt`, порядок семёрки и набор `id` не меняются.

## Решение

### 1. `category` на всех отгружаемых пресетах

`null` больше не используется в каталоге. Семёрка чипов получает жанр ближайшей карточки:

| id | category | subcategory |
|---|---|---|
| `plan_week` | `life` | `planner` |
| `meeting_notes` | `work` | `documents` |
| `tasks_from_photo` | `work` | `documents` |
| `design_brief` | `work` | `ideas` |
| `daily_review` | `life` | `planner` |
| `summarize_text` | `work` | `editor` |
| `project_structure` | `work` | `documents` |

18 агентов сохраняют раскладку ADR-080.

Клиент, который фильтровал `category != null` как «только агенты», теперь увидит и чипы. Новый дискриминатор экрана «Агенты»:

```
presets.filter { $0.id == $0.subcategory }
```

Это ровно 18 карточек со скрина. Старый клиент без `category` / `subcategory` / `description` поля игнорирует.

### 2. Аддитивное поле `subcategory`

Закрытый набор slug'ов = `id` восемнадцати карточек. Стабилен, не локализуется. На карточке агента `subcategory == id`. На чипе — указатель на ближайшую карточку.

### 3. Аддитивное поле `description`

Локализованная однострочная подпись (`en` / `ru` / `zh-Hans`), per-field EN-fallback как у `title`/`prompt`. RU-тексты агентов — со скрина дизайна. Поле всегда присутствует в JSON (пустая строка только у синтетических записей в тестах).

## Что не меняется

- `id`, `title`, `icon`, `prompt`, `locale`, порядок (сначала семь чипов, затем 18 агентов).
- Auth / rate-limit / отсутствие БД / провайдер-агностичность.
- Старые клиенты: неизвестные ключи `JSONDecoder` пропускает.

## Последствия

Смена подписи или перенос чипа в другой жанр = деплой backend, без релиза App Store. Тело ADR-080 не переписано (immutability); правило «чипы = `category: null`» здесь снимается.
