# ADR-080 — Категория пресета (`work` / `life` / `entertainment`) на `GET /v1/presets`

- **Статус:** Accepted
- **Дата:** 2026-08-18
- **Связано:** [ADR-035](ADR-035-prompt-presets-endpoint.md) (каталог пресетов), [ADR-049](ADR-049-presets-localization.md) (локализация `title`/`prompt`)

## Контекст

Экран «Агенты» в iOS раскладывает 18 карточек по трём вкладкам: Работа / Жизнь / Развлечения. Состав уже отдаёт `GET /v1/presets` (карточки дописаны после исходных семи чипов), но жанр клиент хардкодит по `id`. Нужен серверный признак, чтобы вкладки собирались из ответа и не требовали релиза приложения при смене раскладки.

Ограничение: **живые iOS-приложения на тех же инстансах не должны ломаться.** Поля `id` / `title` / `icon` / `prompt`, порядок семёрки чипов и набор `id` не меняются.

## Решение

### 1. Аддитивное поле `category`

Каждый элемент `presets[]` получает `category`:

| Значение | Вкладка iOS | Кто несёт |
|---|---|---|
| `null` | не агент | исходные 7 чипов главного экрана |
| `work` | Работа | `editor`, `letters`, `analyst`, `ideas`, `code`, `documents` |
| `life` | Жизнь | `finances`, `advisor`, `planner`, `studies`, `translator`, `health` |
| `entertainment` | Развлечения | `creator`, `movies`, `quizzes`, `companion`, `stories`, `games` |

Slug стабилен и **не локализуется** (как `id` / `icon`). Подписи вкладок остаются на клиенте.

Поле **всегда присутствует** в JSON (`null` или slug), чтобы новый клиент мог писать `String?` без `decodeIfPresent`-особого случая. Старый `Codable` без свойства `category` игнорирует ключ — это поведение `JSONDecoder` по умолчанию; тот же класс изменения, что `locale` в [ADR-049 §5](ADR-049-presets-localization.md).

### 2. Что не меняется

- `id`, `title`, `icon`, `prompt`, `locale`.
- Порядок: сначала семь чипов, затем 18 агентов.
- Локализация только `title`/`prompt`; `category` одинаков во всех локалях.
- Auth / rate-limit / отсутствие БД / провайдер-агностичность.

## Последствия

Новый iOS: экран агентов = `presets.filter { $0.category != nil }`, вкладки = группировка по `category`. Старый iOS: те же чипы/карточки, лишнее поле не читает. Смена жанра = деплой backend, без релиза App Store.
