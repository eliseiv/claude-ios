Единственный источник истины. Любое расхождение `docs/` ↔ код — дефект.

> ⛔ **Ссылка на код даётся ИМЕНЕМ (функция, константа, класс, модуль), а не номером строки.**
> Номер строки — факт с истекающим сроком: он протухает от чужого рефакторинга и, что коварнее, от
> **собственного дифа той же волны**, при этом не падает ни один гейт — `docs/` не компилируются,
> и разъезд виден только глазами следующего читателя. Имя переживает перемещение кода и
> проверяется `grep`'ом за секунду. **Обязательно** там, где файл меняется активной волной; для
> уже закрытых документов действует при следующем касании — переписывать историю ради формата
> ссылки не нужно. Диапазон строк допустим лишь как **дополнение** к имени
> (`parse_moderation_block_categories`, `src/app/config.py`), никогда как единственный адрес.
